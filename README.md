# QR File Drop

Aplicativo Desktop em C# (Windows Forms) para transferência temporária de arquivos do celular para o PC via QR Code na rede local (Wi-Fi/LAN).

## Funcionalidades
- **Escolha imediata da pasta:** Ao abrir o aplicativo, a pasta de destino é selecionada imediatamente.
- **Instalador automático de dependências:** Verificador e instalador automático da biblioteca QRCoder.dll via NuGet.
- **Servidor HTTP/TCP local:** Servidor HTTP/TCP rodando na rede Wi-Fi/LAN local.
- **Link temporário e expiração:** O link temporário aguarda o término dos uploads até o encerramento da sessão no celular.
